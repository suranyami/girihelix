# Sanzo Wada colour combinations

`colors.json` is vendored, unmodified, from
[dblodorn/sanzo-wada](https://github.com/dblodorn/sanzo-wada), the data behind
<https://sanzo-wada.dmbk.io>.

- Pinned commit: `bedc528f85af521a36cedce91ea3398971139626`
- Path in that repository:
  `apps/sanzo-wada-alpha/assets/colors.json`
- Measured contents: 157 colours and 348 numbered combinations, each
  combination holding 1–5 colours. Each colour carries its index, name, slug,
  hex, CMYK/RGB values and the combinations it belongs to.

The combinations ultimately derive from Sanzo Wada's *Haishoku Sōkan*
(配色総鑑, 1933) and his earlier *Shikisai Sōkan* (色彩総鑑, 1918), the two
dictionaries of colour combinations that the modern dataset reconstructs.
